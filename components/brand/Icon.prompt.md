Thin-stroke Lucide icon; use for all UI glyphs (arrows, calendar, clock, map pin, value-prop icons).
```html
<script src="https://unpkg.com/lucide@0.460.0/dist/umd/lucide.min.js"></script>
```
```jsx
<Icon name="arrow-right" size={16} />
<Icon name="leaf" size={28} strokeWidth={1} color="var(--mx-gold)" />
```
- Keep strokeWidth 1–1.5. Never fill icons.
